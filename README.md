An editorial-grade, modern, and highly interactive developer portfolio engineered with **pure vanilla web technologies** (HTML5, CSS3, JavaScript ES6+) and zero external framework dependencies.

## 🚀 Key Features & Architectural Highlights

- **Bespoke Editorial & Cyber Theme**: Deep obsidian background with ambient grid overlay, hairline border framing, and precision accents (Cyber Emerald & Safety Amber).
- **Interactive Cyber Terminal HUD**: 3D-tilt telemetry card with real-time mouse interaction and system specs.
- **Interactive Laser Security Bench**: In-browser optical perimeter simulation widget with live beam obstruction and synthetic **Web Audio API** 2.4kHz piezoelectric tone.
- **Academic Credentials**: Integrated showcase for **B.Tech Computer Science & Engineering (Specialization: Cybersecurity)** from **SRMU**.
- **Asymmetrical Bento Grid**: Creative philosophy narrative, academic pedigree, and dual frontend/security focus.
- **Client-Side Validation**: Defensive form handling with real-time feedback and simulated encrypted dispatch.
- **Theme Engine**: Instant Dark/Light theme switching with persistent `localStorage` memory.
- **Accessibility & Performance**: Semantic HTML5 document hierarchy, WCAG 2.1 contrast compliance, and smooth 60fps micro-interactions.
